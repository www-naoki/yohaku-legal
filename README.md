# yohaku-legal

iOS アプリ **余白 (Yohaku)** の法務文書を GitHub Pages で公開するリポジトリです。

- 利用規約: https://www-naoki.github.io/yohaku-legal/terms/
- プライバシーポリシー: https://www-naoki.github.io/yohaku-legal/privacy/
- 免責事項: https://www-naoki.github.io/yohaku-legal/disclaimer/

正データは Yohaku 本体リポジトリの `docs/legal/*.md` です。本リポジトリの HTML はそこから生成しています。
**本文を直接編集せず、必ず `docs/legal/` を更新してから反映してください**（二重管理を避けるため）。

本書は本アプリ開発者が作成したものです。弁護士その他の専門家によるレビューは受けていません。
